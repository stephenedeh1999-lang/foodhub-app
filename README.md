# 🍔 FoodHub - Food Delivery App

A modern food ordering web application with real-time cart management and order placement.

## ✨ Features

- 🍽️ Browse menu with categories
- 🛒 Add/remove items from cart
- 📱 Responsive design
- 🌙 Clean UI with smooth animations
- 💾 Order history saved locally
- ✅ Order placement with customer details

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage for data persistence
